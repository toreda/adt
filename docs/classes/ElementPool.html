    Class ElementPool<ElementT>

    Element wrapper pooling shared by every node-based data structure. Wraps an optional ObjectPool of the data structure's own element class behind one gate: when pooling is disabled the pool is never created and every call falls through to plain allocation. Data structures hold one of these per element type; array-backed data structures hold none.
