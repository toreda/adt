    Class DirectedGraphVertex<T>

    Vertex wrapping one item in a DirectedGraph. Implements ObjectPoolInstance so the graph can recycle vertices through an internal ObjectPool. Edges are read-only from outside: only the graph links and unlinks them, so both ends of every edge always agree.

    cleanObj

    • cleanObj(): void

      Reset every field to its blank state. Called by ObjectPool on release so a recycled vertex never carries a previous item or its edges. Any new field added to this class must be cleared here.

      The edge maps are emptied, not replaced. An empty map is left untouched, so recycling a vertex whose edges were already removed (as DirectedGraph.removeVertex() does) allocates nothing. Clearing a map that still holds edges lets the engine allocate a fresh backing table (V8 does), which only happens when a whole graph is cleared at once.

      Returns void

        Array to fill instead of allocating a new one. It is overwritten by index and then cut to the result count, so its storage is reused while the count stays the same.
