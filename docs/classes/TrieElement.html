    Class TrieElement<T>

    Node in a Trie. Each node stands for one key prefix: the root for the empty prefix, and every other node for its parent's prefix plus one UTF-16 code unit. A node whose prefix is a whole key is terminal and holds that key's item; other nodes only link to longer prefixes. Implements ObjectPoolInstance so the trie can recycle nodes through an internal ObjectPool. Links are read-only from outside: only the trie rewires them.

        Optional array to fill and return instead of a new one.

      Returns TrieElement<T>[]

      Remarks

      Allocates a new array per call unless out is given. out is overwritten by index and then cut to the child count, so its storage is reused while the count stays the same. V8 frees an array's storage when its length drops to 0 and trims it when the length shrinks, so a leaf after a parent, or a larger count after a smaller one, still allocates. On a hot path, use child() instead, which allocates nothing.

      Parameters

      • OptionalelementValue: T

      Returns T | null

      Remarks

      While the node is linked into a trie, a new value is only accepted on a terminal node, and only when the trie's key selector returns the node's key for it (e.g. replacing an item with an updated copy under the same key). Any other value would be stored under the wrong key, so it is ignored: use the trie's update() instead, which moves the item when needed.
