    Class ByteStack<ItemT>

    Stack that can always be converted to and from bytes. The item codec is required at construction, so toBytes() and toByteEnvelope() never fail for lack of one. Everything else is inherited unchanged.

    The envelope holds items in collection order, top to bottom, as forEach and iteration visit them. The constructor pushes decoded items bottom first, so the rebuilt stack has the same top.
