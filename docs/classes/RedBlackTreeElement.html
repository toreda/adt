    Class RedBlackTreeElement<T>

    Node wrapping one item in a RedBlackTree. Implements ObjectPoolInstance so the tree can recycle nodes through an internal ObjectPool. Links and color are read-only from outside: only the tree rewires or recolors them, since any other change could break its ordering or balance.

      Existing children, left before right.

      Parameters

      • Optionalout: RedBlackTreeElement<T>[]

        Optional array to fill and return instead of a new one.

      Returns RedBlackTreeElement<T>[]

      Remarks

      Allocates a new array per call unless out is given. out is overwritten by index and then cut to the child count, so its storage is reused while the count stays the same. V8 frees an array's storage when its length drops to 0 and trims it when the length shrinks, so a leaf after a parent, or a larger count after a smaller one, still allocates. On a hot path, read left() / right() instead, which allocate nothing.

      Parameters

      • OptionalelementValue: T

      Returns T | null

      Remarks

      While the node is linked into a tree, a new value is only accepted when the tree's comparator rates it equal to the current one (e.g. replacing an item with an updated copy under the same key). Any other value would break the search order, so it is ignored: use the tree's update() instead, which moves the item when needed.
