    Class ObjectPool<T>

    Pool of reusable object instances. allocate() and release() are O(1) and allocate nothing once the pool has grown: free objects sit on a stack, and each in-use object keeps its own slot in state.used, so a release never searches or compacts. Release moves the last in-use object into the freed slot, so in-use order is not allocation order.

    release() only accepts objects this pool handed out that are still in use. Double releases and objects from elsewhere are ignored, so the pool never holds an object twice and never grows past maxSize.
