    Class ByteGraphEnvelope

    Byte container for a graph: a standard ByteEnvelope holding each vertex's item bytes in vertex order, followed by a section of fixed-size edge records that refer to vertices by index. The vertex envelope is embedded unchanged (version 1), so every other data structure keeps reading and writing plain ByteEnvelope bytes, and graph bytes are told apart by their own magic.

    Layout, all integers little-endian:

    0          u8[4]  magic "TADG"
    4          u8     graph format version
    5          u32    vertex envelope length (L)
    9          u8[L]  vertex envelope: a complete ByteEnvelope ("TADT")
    9 + L      u32    edge count (m)
    13 + L     m x {u32 from, u32 to, f64 weight, u8 flags}   edge records

    Flags bit 0 marks a bidirectional edge; every other bit must be 0.

    Full specification: _specs/byte-envelope.md.
